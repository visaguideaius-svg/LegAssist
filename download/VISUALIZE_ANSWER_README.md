# Visualize Answer Feature — Jordanian Legal Knowledge Platform

## Overview

This feature allows users to convert grounded legal AI answers into branded, downloadable infographic visuals. The infographic is a structured visual summary — it does NOT create new legal analysis or add independent claims.

## Architecture

```
Grounded legal answer (from chat)
  → Answer validation (disclaimer, sources, high-risk check)
  → InfographicSpec JSON generated by LLM
  → Zod schema validation
  → Deterministic React/SVG renderer
  → Browser preview with responsive scaling
  → PNG & PDF export via html-to-image + jsPDF
```

## Setup

### Prerequisites

- Node.js 18+ (Bun also supported)
- SQLite (included via Prisma)
- Next.js 16 with Turbopack

### Installation

```bash
npm install
npx prisma db push
npx tsx scripts/seed.ts
npm run dev
```

## Database

The feature adds a `visualizations` table to the existing Prisma schema:

| Column | Type | Description |
|--------|------|-------------|
| `id` | String (cuid) | Primary key |
| `topic_id` | String? | Optional FK to topics |
| `source_answer_hash` | String | SHA-256 hash of the input answer |
| `language` | String | "ar" or "en" |
| `template` | String | legal-summary / procedural-guide / document-checklist / deadline-warning |
| `input_answer` | String (text) | Original answer text |
| `infographic_spec` | String (JSON) | Zod-validated InfographicSpec |
| `status` | String | "generated" / "needs_review" / "failed" |
| `rendered_image_path` | String? | Path to PNG export |
| `rendered_pdf_path` | String? | Path to PDF export |
| `generated_by_model` | String? | LLM model used |

## Environment Variables

No additional environment variables beyond the existing project setup. The feature uses:

- `DATABASE_URL` — SQLite connection (existing)
- `ZAI_*` — AI SDK configuration (existing, auto-configured)

## API Routes

### POST `/api/visualizations`

Create an infographic from a legal answer.

**Request:**
```json
{
  "answerId": "uuid",
  "answerText": "The legal answer text...",
  "language": "ar",
  "template": "legal-summary"
}
```

**Response (200):**
```json
{
  "id": "cuid-string",
  "status": "generated",
  "spec": { /* InfographicSpec object */ }
}
```

**Error (422):** LLM output failed Zod validation.

### GET `/api/visualizations/[id]`

Fetch a visualization record by ID.

### POST `/api/visualizations/[id]/regenerate`

Re-generate the InfographicSpec for an existing visualization while preserving the original legal answer.

## InfographicSpec Schema (Zod)

Defined in `src/lib/infographic-schema.ts`:

- `language`: "ar" | "en"
- `direction`: "rtl" | "ltr"
- `jurisdiction`: "Jordan" (literal)
- `template`: one of 4 templates
- `title`, `subtitle`: text fields
- `urgency`: optional banner with severity levels
- `sections[]`: 2-5 sections with icon, layout, items/columns
- `sources[]`: 1-4 verified legal sources
- `disclaimer`, `last_reviewed`: required fields
- `branding`: color configuration

## Templates

### 1. Legal Summary (`legal-summary`)
General legal explainers. Sections: What is the issue → Key factors → Possible outcomes → What to do now → When to consult a lawyer.

### 2. Procedural Guide (`procedural-guide`)
Step-by-step procedures. Sections: First action → Documents → Relevant authority → Deadlines → Escalation.

### 3. Document Checklist (`document-checklist`)
Evidence & document-focused. Sections: Essential documents → Supporting evidence → Private documents → Lawyer questions.

### 4. Deadline Warning (`deadline-warning`)
Time-sensitive topics. Sections: Why it matters → Trigger date → Immediate actions → Documents to preserve → Urgent help.

## Export Pipeline

### PNG Export
Uses `html-to-image` (`toPng`) to render the infographic DOM at 2x pixel ratio.

### PDF Export
Combines `html-to-image` → `jsPDF` to create a downloadable PDF at the correct aspect ratio.

## RTL/LTR Support

- Arabic infographics render with `dir="rtl"`, right-aligned text, Noto Kufi Arabic font
- English infographics render with `dir="ltr"`, left-aligned text, Inter font
- The language is set from the InfographicSpec `direction` field

## Legal Safety

1. **No new legal content**: Only uses facts from the approved answer.
2. **Source validation**: Missing sources block publication (status: `needs_review`).
3. **High-risk detection**: Criminal, family violence, custody, urgent eviction keywords trigger `needs_review`.
4. **Disclaimer preservation**: Original disclaimer is always included.
5. **Uncertainty preservation**: Qualifying language is never removed.

## Adding New Templates

To add a new infographic template:

1. Add the template name to the `template` Zod enum in `src/lib/infographic-schema.ts`
2. Add template selection guidance in `src/lib/visualization-system-prompt.ts`
3. Optionally, add a new layout type in `InfographicSection.tsx` if the section structure differs
4. Test with `npx vitest run` if applicable

## Storage Configuration

Currently, PNG/PDF exports are generated client-side and downloaded directly. For server-side storage:

1. Set up an S3-compatible bucket (Supabase Storage, etc.)
2. Add `STORAGE_URL`, `STORAGE_KEY`, `STORAGE_SECRET`, `STORAGE_BUCKET` to `.env`
3. Implement server-side render in `/api/visualizations/[id]/render` using Playwright
4. Store paths in `rendered_image_path` and `rendered_pdf_path`
